# Tahir Murtaza — Week 1: See It Work

**Week:** 1 — See It Work
**Author:** [TahirMurtaza](https://github.com/TahirMurtaza)

## What this contains

A self-hosted n8n automation that scans job postings daily, scores each one
against my resume with Gemini, checks ATS keywords, drafts a cover letter, and
queues the result in Google Sheets for manual review.

See [automate_jobs/README.md](automate_jobs/README.md) for full setup and run
instructions.
